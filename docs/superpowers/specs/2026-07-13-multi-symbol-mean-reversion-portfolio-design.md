# 多币均值回归组合策略 — 设计文档

- 日期: 2026-07-13
- 状态: 已批准(方向),待实现
- 取代对象: 不取代。老策略 `strategies/consecutive_reverse.py`(马丁格尔)实盘保留,本设计为独立新策略。

## 1. 背景与问题

现有实盘策略 `consecutive_reverse.py`(连续K线反向 + 马丁格尔加仓)存在两个结构性缺陷,已用 6.4 年 BTCUSDT 1h 真实数据验证:

1. **几乎不开仓**:`CONSECUTIVE_THRESHOLD=7` 要求连续 7 根同色 1h K线才首次开仓,仅 0.63% 的 bar 满足(约每 6.6 天一次机会);且实盘冷启动不预热,连续计数从 0 现攒。
2. **一旦开仓会爆仓**:`POSITION_MULTIPLIER=2.9` + `INITIAL_POSITION_PCT=1.19` 的反向马丁在单边趋势里指数级加仓(连7→1.19×,连10→29×,连12→244× 名义/余额),回测 2024–2026 净收益 −271%、最大回撤 195%。

### 关键数据发现(edge 分析)

- "连续 N 根后 fade"方向**胜率稳定在 ~57–61%**(跨门槛、跨周期),均值回归倾向真实存在。
- 但**单笔毛利极小(+0.01%~+0.06%)**,小于吃单往返费。拉长持仓/加波动率过滤器/换 4h 均**无法**稳健放大均值。
- OKX 合约费率:**maker 0.02%/边、taker 0.05%/边**。
- 结论:真正可利用的是**胜率**,不是均值。把它当"~58% 胜率的方向性下注",配合 maker 入场 + 对称止盈止损,期望可转正:
  `E = t·(2p−1) − fee_rt`;p=0.58、maker 往返 0.04% 时,t>0.13% 即正期望,t=0.5% 时约 +0.04%/笔。
- 单币 edge 薄 → 用**多币组合分散**提升稳定性/Sharpe(本设计核心)。

## 2. 目标与非目标

- **目标**:构建一个多币、均值回归、固定仓位 + maker 入场 + 止盈止损的组合策略,做到**样本外(OOS)稳健正期望**。
- **非目标**:不追求"保证盈利";不重做信号层(RSI/布林/资金费率等,属备选方案 C,仅在 OOS 为负时启动);本阶段不含实盘多币接入(后续独立阶段)。

## 4. 信号(每币独立,参数全币共享)

- K线方向:`close>open`=+1,`close<open`=−1,十字星跳过(不影响连续计数)。
- 连续 N 根同色后**反手**:连涨→做空,连跌→做多。N≈4–5。
- **所有可调参数全币共享一套**(N、TP、SL、H、r、入场偏移),抗过拟合。

## 5. 入场执行(maker)

- 用**限价单**挂在反弹侧:做空挂 `close×(1+offset)`,做多挂 `close×(1−offset)`,吃 maker 0.02%。
- 限价单在信号 bar 之后挂出,有效期为 M 根 bar,未成交则撤单(避免过期错价成交)。
- **漏单建模**:回测须如实反映"价格未回踩到限价→漏掉该笔"。漏单率 + 净edge 作为验收指标。

## 6. 出场(bracket)

引擎无原生 stop 单,采用 bar 级近似:

- 每根 K线检查持仓:
  - 触及止盈 `TP=+t%` → 限价平仓(maker 0.02%)
  - 触及止损 `SL=−s%` → 市价平仓(taker 0.05%)
  - 持仓达 `H` 根 → 市价强平(时间止损)
- 同一根 bar 同时触及 TP 和 SL → **保守假设先触发 SL**。
- 参数区间:t、s ∈ [0.3%, 1.5%],初始对称或略偏止盈(t≥s);H ∈ [2, 24]。
- **费率非对称建模**(必须):止盈往返 0.04%,止损往返 0.07%。EV 与回测一律用真实非对称费率,不得用单一费率近似。

## 7. 仓位与组合风控(无马丁)

- 固定风险:每笔风险 `r%×净值`(r≈0.5%),名义仓位 `= r%×equity / s%`。
- 每币同时最多 1 个仓位。
- 全组合并发持仓上限 K(复用 `PortfolioBacktestEngine.max_position_symbols`)。
- 总保证金占用上限(防止 10 币同时开仓爆保证金)。

## 8. 验证方案(上线红线)

- **样本内**:2022-01 → 2024-12 优化参数。
- **样本外**:2025-01 → 2026-07 验证(不参与调参)。
- **验收红线**(全部满足才考虑上线):
  1. OOS 组合净收益 > 0
  2. OOS Sharpe > 0
  3. OOS 平均单笔净收益(扣真实非对称费)> 0
  4. 最大回撤在可接受范围(目标 < 25%)
- 报告输出:组合净值曲线、每币贡献分解、总/每币胜率、平均单笔净收益、漏单率、并发持仓分布。
- 若 OOS 为负 → **不上线**,升级到备选方案 C(重做信号层)。

## 10. 默认决策(已确认)

- 时间周期:**1h**(交易多、利于组合分散)。
- 出场:**TP/SL bracket**(EV 数学干净),不保留老的"反向K线/盈利计数"出场。

## 11. 风险与前提

- edge 本身很薄,单币方差大;组合分散是主要稳健性来源,前提是跨币 edge 大致独立。
- maker 入场的漏单/逆向选择可能吃掉部分理论 edge,须在回测中量化。
- 加密币相关性高(尤其山寨跟随 BTC),分散效果可能弱于理论,需在报告中检查每币贡献与相关性。
